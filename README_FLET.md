# 🏠 家纺记账系统 - 苹果风格版

基于 Flet 框架重写的现代化记账应用，采用苹果风格设计。

> 这是当前仓库的 **主客户端**。Tk 版本已进入维护态，后续新能力优先落在 Flet 版。

## ✨ 特性

### 🎨 设计风格
- **苹果紫主题** - 优雅的紫色配色方案
- **圆角卡片** - 现代化的卡片式布局
- **流畅动画** - 悬停效果和过渡动画
- **阴影效果** - 立体感的视觉层次
- **响应式布局** - 自适应窗口大小

### 📝 核心功能
- ✅ **多商品录入** - 一次录入多个不同单价的商品
- 🔄 **销售/退货** - 支持销售和退货两种类型
- 📊 **实时统计** - 今日销售统计自动更新
- 🗂️ **记录管理** - 编辑备注、删除记录
- 🔍 **筛选查看** - 今天/本月/本年/全部记录切换
- 💾 **数据持久化** - 自动保存到本地 JSON 文件

## 🚀 运行方式

### 方式一：直接运行
```bash
python accounting_flet.py
```

### 方式二：打包为 exe
```bash
# 安装打包工具
pip install pyinstaller

# 打包
pyinstaller --name="家纺记账系统" --windowed --onefile accounting_flet.py
```

## 📖 使用说明

### 添加记录
1. 选择日期（默认今天）
2. 选择类型（销售/退货）
3. 填写商品明细：
   - 输入数量和单价
   - 点击"+ 添加商品"可添加多个商品
4. 填写备注（可选）
5. 点击"✅ 添加记录"

### 管理记录
- **编辑** - 点击记录卡片右侧的编辑图标
- **删除** - 点击记录卡片右侧的删除图标
- **筛选** - 使用顶部的"今天/本月/本年/全部"按钮

### 查看统计
- 左侧底部显示今日统计
- 右侧底部显示当前筛选范围的合计金额
