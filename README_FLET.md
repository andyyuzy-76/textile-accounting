# 🏠 家纺记账系统 - 苹果风格版

基于 Flet 框架重写的现代化记账应用，采用苹果风格设计。

> 这是当前仓库的 **主客户端**。Tk 版本已进入维护态，后续新能力优先落在 Flet 版。

## ✨ 特性

### 🎨 设计风格
- **苹果蓝主题** - 清爽的蓝色配色方案
- **圆角卡片** - 现代化的卡片式布局
- **流畅动画** - 悬停效果和过渡动画
- **阴影效果** - 立体感的视觉层次
- **响应式布局** - 自适应窗口大小

### 📝 核心功能
- ✅ **多商品录入** - 一次录入多个不同单价的商品
- 🔄 **销售/退货** - 支持销售、独立退货记录、原单追加销售
- 📊 **统计分析** - 今日统计 + 月度统计弹窗
- 🗂️ **记录管理** - 编辑商品明细/备注、删除记录、查看明细
- 🔍 **筛选查看** - 今天/本月/本年/全部记录切换
- 💾 **数据持久化** - 自动保存到本地 JSON 文件
- ☁ **云端备份** - WebDAV 手动/自动备份、完整性校验、历史备份恢复（Windows）
- 🧾 **打印链路** - 打印设置、预览、保存文本、自动打印
- 📥 **导入导出** - CSV / Excel 导入与 CSV 导出
- 🔄 **版本维护** - 系统设置与检查更新入口

## 🚀 运行方式

### 方式一：直接运行
需要 Python 3.10+，先安装锁定版本的运行依赖：

```bash
pip install -r requirements.txt
python accounting_flet.py
```

当前锁定 Flet / flet-desktop 0.81.0，请勿随意升级。Excel 导入等可选依赖见 `requirements.txt` 中的注释。

### 方式二：打包为 exe（推荐使用 Flet 打包脚本）
```bash
build_flet.bat
```

## 📖 使用说明

### 添加记录
1. 选择日期（默认今天）
2. 点击每行的类型按钮，在销售和退货之间切换
3. 填写商品明细：
   - 输入数量和单价
   - 点击"+ 添加商品"可添加多个商品
4. 填写备注（可选）
5. 点击"✅ 添加记录"

### 管理记录
- **编辑** - 点击记录卡片右侧的编辑图标
- **删除** - 点击记录卡片右侧的删除图标
- **筛选** - 使用顶部的"今天/本月/本年/全部"按钮

### 查看统计
- 左侧底部显示今日统计
- 右侧底部显示当前筛选范围的合计金额
- 月度统计与今日统计使用相同口径，按商品明细分别累计销售和退货；混合单即使净数量或净金额为零，也不会漏计

### 云端备份

点击顶部云朵图标，或「系统设置 → 云端备份」，填写 WebDAV 地址、账号和应用密码，先「测试连接」再「立即备份」。按需开启自动备份；保存账目、导入数据、删除记录和修改客户/打印设置后约 5 秒自动执行，内容不变则跳过。

备份包含账目、客户列表和打印设置。使用「刷新历史 → 恢复所选备份」恢复，确认前会校验云端文件，恢复前会保留本地原始文件副本。

备份文件本身未加密，请使用私有网盘。密码使用 Windows DPAPI 在本机加密保存，不进入云端备份。完整配置、恢复位置及断网重试说明见 [README 的云端备份章节](README.md#云端备份windows-flet-版)。
